Proven strategies (what experts actually agree on)

These are the approaches most respected SAT tutors and test-prep orgs converge on. They are habits, not hacks — drill them until automatic.

RW strategies

  • Predict before you look. For Vocab-in-context, cover the choices and say the blank's job in your own words, then match one exact choice. (Expert consensus: predicting kills the 'it sounds right' trap.)
  • Read for argument structure. For Main Idea / Inference, ask: claim → evidence → implication. If a choice adds a new claim, it is wrong.
  • Transition = relationship, not vocabulary. State the relationship first: same, opposite, cause, example, sequence. Then pick the connector whose core meaning matches.
  • Purpose questions: what does it DO? Not what it says, what it proves, or what it mentions. Name its role in the paragraph, then match.
  • Grammar: find the subject, then the anchor. Agreement, tense, pronoun reference all attach to the same noun. Cross out prepositional phrases before deciding.
  • Boundaries: classify each side first. Independent or dependent clause? That one test eliminates most punctuation errors.

Math strategies

  • Start with structure, not arithmetic. Linear? Quadratic? Exponential? Name the type, then choose the fastest tool: Desmos graph, symbolic solve, or arithmetic.
  • Use Desmos for intersections, not expressions. Graph both sides, read the crossing. When the answer is symbolic, use solve(...) or regression to confirm.
  • Always check the domain. Even in rational and radical equations: original denominators ≠ 0. Reject any candidate that breaks it.
  • Percent/ratio: write the equation in words. 'is' = '=', 'of' = '×', 'percent' = '/100', 'more than' = '+', 'times as much' = '×'. Most errors are word-parsing errors.
  • Geometry: mark what you know. Add tick marks for equal lengths, label angles, write the radius before touching an arc/sector.
  • Data questions: units, direction, conditions. Correct answer must match every stated qualifier. A true statement with a wrong qualifier is the classic distractor.

Test-day habits

  • Flag aggressively. If you are not 80% sure within 30 seconds, mark it and move. Return with 5–10 minutes left.
  • Never leave anything blank. Wrong and unanswered score the same — so guess. Then review only flagged items.
  • Pacing checkpoints. RW: ~27 Q in 32 min → ~70s/Q. Math: ~22 Q in 35 min → ~95s/Q. If one question is eating your buffer, bank the next three instead.
  • Desmos > algebra when the answer is a coordinate or value. Use symbolic algebra when the answer is an expression, parameter, or inequality.
  • Take the real breaks. Two sections with a 10-minute break between them is designed fatigue management. Use it for water and reset, not review.

Study method (spaced + tested)

  • Alternate study / test / review. Read a type card → do 3 from that type → review every miss. Passive re-reading without testing does not move scores.
  • Keep an error log with cause tags. Boundary, vocab, inference, system, trig, arithmetic. Most people have only 3–5 real causes — drill those, skip the rest.
  • Sleep is the last-minute strategy. The night before: no new topics after 8pm. Test day is retrieval, not learning.

Exam day

Night before / morning

  • ID + admission ticket + approved calculator (backup batteries) + snack + water.
  • Know your Bluebook login. Test the app opens.
  • Sleep > extra drill. No new content after 9pm.
  • Breakfast + arrive 30 min early. Bathroom before check-in.

In the room

  • RW: 1 pass, flag long ones, never >90s on one Q in Module 1 (you need Hard Module 2).
  • Math: Desmos graphing tab by default; check degrees/radians before trig.
  • Flag + move on; return with 5 min left. Guess every blank.
  • SPR: no negative exponents confusion — enter 3/8 or .375, never 3 / 8 spaces issue; preview your entry.
